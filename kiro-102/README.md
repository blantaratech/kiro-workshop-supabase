# Kiro 102 student guide

[All lessons](../README.md) · **Lesson 2 of 2** · [Previous: Kiro 101](../kiro-101/README.md)

Open **[STUDENT_GUIDE.html](STUDENT_GUIDE.html)** in a browser. It includes a contents menu, copy buttons and Print / Save as PDF.

This companion to the Supabase startup kit teaches a small requirements-first Kiro feature and Jebat MCP setup. It does not include an implemented search feature or install/configure anything on your computer automatically.

| File | Use |
| --- | --- |
| `STUDENT_GUIDE.html` | Main student lesson; readable offline, with internet needed for the actual tools |
| `STUDENT_GUIDE.md` | Editable lesson source |
| `config/` | Secret-free example JSON for remote Bearer, remote X-API-Key and local stdio connections |
| `examples/` | Reference requirements, design, tasks and a blank student worksheet |
| `REFERENCES.html` | Official Kiro and Jebat documentation for further reading |

Start with the [Kiro 101 setup guide](../kiro-101/STUDENT_SETUP_GUIDE.html) if the app is not running. Get the app from the repository linked in Kiro 101. If you received a separate student guide ZIP, it includes both lesson folders but not the app source or dependencies.

The HTML has embedded styling and scripts, with no CDN, web-font or analytics dependency. Example paths and access-key references must be configured by each student; the examples contain no usable credential.
